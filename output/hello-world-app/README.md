# hello-world-app

## 项目简介
这是一个简单的 'Hello World' 页面应用。

## 技术栈
- 后端语言: Node.js
- 后端框架: Express
- 前端: Vanilla HTML + JavaScript

## 前置依赖
Node.js 版本 >= 14.0.0

## 安装步骤
1. 克隆项目仓库到本地。
2. 进入项目目录。
3. 运行 `npm install` 安装依赖。

## 启动步骤
1. 确保 Node.js 已安装。
2. 在项目根目录下运行 `npm start`。

## 访问地址
http://localhost:3000/

## API 列表
本项目没有对外提供 API。

## 目录结构
```
hello-world-app/

│   └── styles.css
```
